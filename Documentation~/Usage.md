# 使用 Inspector Wingmate

选中场景对象，在组件列表中单击名称即可隔离该组件。Ctrl（macOS 用 Command）切换多个组件，Shift 连续选择。All 恢复全部组件。Lock 保持当前对象，即使 Hierarchy 选择已经改变。

搜索框按字段的显示名称和序列化路径过滤当前组件，点击清除按钮恢复原来的自定义 Inspector。Copy 保存当前组件选区的值。选中另一对象后点 Paste 即可粘贴。已有的同类型组件按出现次序对应，新组件支持 Undo。Transform 复制本地姿态。剪贴板保存在此次编辑器会话中。

把组件名称拖到 Hierarchy 中的目标上，可直接复制到该对象。拖到空白处会新建一个对象。预制件可在 Prefab Mode 中操作。

右键组件名称可以隔离、切换选区、复制或粘贴。返回最近查看的对象时，窗口会恢复它的组件选区和搜索词，最多记住 32 个对象。Options 可关闭此功能、改用精确子串搜索或缩小组件按钮的间距。默认搜索支持按顺序输入字符，例如 `c n t r` 可找到 Center。

窗口复用最近四个对象的组件控件，只有正在查看的对象接入面板。关闭场景会释放该场景的控件及闲置的剪贴板缓冲。
