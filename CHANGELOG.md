# Changelog

## 1.1.0

Added native Inspector and component context menu commands, per-object selection and search history, fuzzy field matching and window preferences. The clipboard reuses its native buffers when alternating component types and releases spare buffers when a scene closes.

## 1.0.1

Avoid redundant component styles and search resets. Added coverage for switching the visible component, field visibility and repeated clipboard updates.

## 1.0.0

Initial public release with component isolation, field search, locking, snapshot copy and hierarchy drag and drop.
