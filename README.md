# Inspector Wingmate

Unity 6.6 编辑器插件。在一个可停靠的 Inspector 中隔离组件、搜索序列化字段、固定对象、复制组件或把组件拖到 Hierarchy。

在 **Window → Package Management → Package Manager → ＋ → Install package from git URL** 中粘贴：

```text
https://github.com/VM233/inspector-wingmate.git#v1.0.0
```

从 **Window → General → Inspector Wingmate** 打开。包名为 `com.vm233.inspector-wingmate`。Editor 程序集位于 `Editor/`，仅依赖 Unity 编辑器。 [操作说明](Documentation~/Usage.md) · [更新记录](CHANGELOG.md) · [MIT 许可](LICENSE.md)
